# Zapret Manager Portable 2.0.4

Один файл — **приложение + zapret** внутри. Качайте и запускайте, ничего устанавливать не нужно.

## Как пользоваться

1. Скачайте `Zapret-Manager-Portable-2.0.4.exe`
2. Двойной клик — файл распакуется в папку `Zapret Manager Portable` (Рабочий стол) и запустит приложение
3. Готово

Приложение **полностью портативное**: готовую папку можно переносить на любой диск или флешку.

## Что внутри

| Компонент | Версия |
|---|---|
| Программа | 2.0.4 |
| zapret-discord-youtube | актуальная (в комплекте) |

При первом запуске программа сама находит `zapret` рядом с собой — настройка не нужна.

## Требования

Один раз: **WebView2** (обычно стоит в Windows 10/11) и **VC++ Redist**. Если их нет — установите из официальных источников.
