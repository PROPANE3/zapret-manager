# Zapret manager

Легкое приложение-инструмент, для работы с утилитой Zapret.
Проект предоставляет возможность быстро и гибко проверять работоспособность .bat вашего zapretа, изменять listы.
Помимо этого, все ваши проверки сохраняются в логи, что позволяют быстрее и проще находить рабочие .bat.
У данной утилиты настроено автоматическое обновление Zapret и Zapret manager, чтобы всегда иметь доступ, к актуальной сборке.
Так же имеется fail-safe механизм, с индивидуальной настройкой, автоматически ищущий рабочий .bat при поломке текущего.
И вишенка на торте - красивое оформление, что делает приятнее повседневное приложение.

## Системные требования

1. Иметь компьютер
2. Иметь python (! версия 3.12+, должен быть установлен с [клац](https://www.python.org/downloads/))
3. (Опционально) Иметь установленный Zapret (оффициальная ссылка [клац](https://github.com/flowseal/zapret-discord-youtube))

## Функционал

### Проверка конфигов

Здесь находится все связанное с вашими батниками. Вы можете выбрать алгоритм проверки батников, ввести дополнительные параметры (количество проверок, максимальный допустимый пинг), выбрать активный батник, а так же в реальном времени видеть результаты проверки. Приятным бонусом являются статусы активности самого запрета и впн.

### Домены

Здесь вы можете указать айпишник, на который будет подменяться ваш, редактировать lists и по большей части это все.

### Логи проверок

Здесь хранятся логи всех ваших предыдущих проверок, на случай, если выбранный батник работает не так, как вам нужно.
