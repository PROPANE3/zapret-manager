# Zapret Manager v2

Панель управления zapret-discord-youtube для обхода DPI.

Поддерживается **2 способа** — выберите свой.

---

## 📦 Пользователям: Portable (рекомендуется)

**Один файл** — всё внутри (приложение + zapret).

- Откройте папку [`portable/`](portable/)
- Скачайте `Zapret-Manager-Portable-2.0.4.exe`
- Запустите — оно само распакуется и откроется
- Работает с любого диска и флешки, без администратора

Подробности и контрольная сумма — в [`portable/README.md`](portable/README.md).

---

## 🔧 Разработчикам / полноценная установка: исходники + Installer.vbs

Полная версия проекта — весь исходный код в этом репозитории.

### Установка из исходников

1. Скачайте архив проекта (зелёная кнопка **Code** → **Download ZIP**)
2. Распакуйте в любую папку
3. Запустите файл **Installer.vbs** (двойной клик)

Установщик сам:
- Проверит и установит зависимости (WebView2, VC++ Redist)
- Скачает **актуальную версию** программы с GitHub
- Скачает и настроит zapret-discord-youtube
- Создаст ярлыки на рабочем столе и в меню Пуск
- Запустит приложение

Ничего делать вручную не нужно — всё автоматически.

### Обновление

Просто запустите **Installer.vbs** снова — он проверит версию и скачает обновление, если вышла новая версия.

### Удаление

Запустите из командной строки:
```
powershell -ExecutionPolicy Bypass -File tools\Setup.ps1 -Uninstall
```

### Сборка из исходников

Консольный установщик с дополнительными возможностями:
```
tools\Setup.ps1                  — установка
tools\Setup.ps1 -CheckOnly       — только проверка (ничего не меняет)
tools\Setup.ps1 -Rebuild         — пересобрать из исходников (нужен Rust)
tools\Setup.ps1 -Uninstall       — удаление
tools\Setup.ps1 -Silent          — тихая установка
```

Требования для сборки: [Rust](https://rustup.rs), [Node.js](https://nodejs.org) (для фронтенда), WebView2. Сборка release: `cargo build --release` в папке `src-tauri`.

## Структура репозитория

```
├── portable/          ← готовая к запуску версия (один файл)
├── frontend/          ← интерфейс (HTML/CSS/JS)
├── src-tauri/         ← приложение (Rust, Tauri 2)
├── tools/             ← установщик и сборка
├── Installer.vbs/.ps1 ← установка полной версии
└── version.txt        ← актуальная версия
```
