# 🔥 Zapret Manager v1.7.2 ([GitHub](https://github.com/PROPANE3/zapret-manager))

Лёгкая панель управления `zapret-discord-youtube` в ало-чёрном дизайне.
Только стандартная библиотека Python — ~15–25 МБ RAM, ноль тяжёлых зависимостей.
Проверено на Python 3.14 + Tk 9.0.
Иконка: белая Z на тёмном скруглённом квадрате (`assets/icon, pre-crop.png` —
авторский исходник, `icon.ico`/`icon.png` собраны обрезкой из него;
копия `icon.png` зашита в `app.py` — иконка есть даже при запуске
без папки assets).

Верхняя шторка — системная, но в цветах темы (Windows 11 красит шторку/текст/рамку
через DWM; рамка гасится в цвет фона). Окно стартует 1480×860 по центру экрана —
все поля видны сразу; видна только активная вкладка, поэтому ресайз лёгкий.
Главная страница листается целиком без перелётов (стоп строго на границах,
ползунок прячется, у текстов/таблиц своё колесо).

## Самый простой запуск (1 клик)

1. Двойной клик по **`install.bat`** — создаст ярлык «Zapret Manager»
   с иконкой Z на рабочем столе.
2. Дальше — двойной клик по ярлыку (права администратора запросятся сами).

То же самое можно сделать из приложения: Настройки → Приложение →
«📌 Создать ярлык на рабочем столе».

## Вкладки

- **🔍 Проверка конфигов** — для каждого конфига меряются пинги Discord и YouTube,
  ставится оценка: **Не работает** (нет пакета, красным), **Плохой** (2000),
  **Средний** (1000), **Хороший** (300), **Отличный** (100). Клик по строке —
  детали по целям, даблклик — применить. Кнопка **▶** у конфига в списке слева —
  применить сразу **без запуска проверки** (диалог: служба+автозагрузка или разово).
  На этой же вкладке: активный конфиг, кнопки **✔ Применить выбранный**,
  **↻ Перезапустить**, **■ Остановить**, баннеры обновлений.
- **🌐 Домены** — просмотр и редактирование файлов `lists/*.txt`
  (с автобэкапом `.bak`; применяется после перезапуска конфига).
- **📋 Логи проверок** — история `data/checks/*.json` в формате:
  используемый конфиг + пинги целевых сервисов + оценка; первой строкой —
  «▶ Последний запуск» с подробным ходом проверки. Лишнее удаляется:
  «🗑 Удалить» выбранный, «🧹 Все» — всё сразу.
- **📝 Журнал действий** — все ручные применения, автопереключения, изменения настроек.
- **⚙️ Настройки** — разделы: Папка, Проверка, Мониторинг, Оформление, Цели, Приложение.

При старте проверяется обновление
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
(сравнение с `LOCAL_VERSION` из `service.bat`) — при наличии баннер с кнопкой релизов.
Так же проверяется обновление самого приложения (`version.txt` в репозитории
[PROPANE3/zapret-manager](https://github.com/PROPANE3/zapret-manager)) —
при наличии баннер с кнопкой «Скачать». Как выпустить обновление:
поменяйте версию в `APP_VERSION` и `version.txt`, закоммитьте, запушьте
и приложите zip к GitHub Release.

## Скорость проверки

- **Быстрый режим (по умолч.)** — только Discord + YouTube + Google (7 целей),
  цели проверяются **параллельно**, HTTP — в 2 повтора (зачёт при первом успехе).
- **Ручная проверка = ТУРБО**: потоков `max(настройка, CPU×2)` до 16 +
  повышенный приоритет процесса на время проверки (потом возвращается).
- **Автомониторинг = ЭКО**: 3 потока, 1 повтор, короткий таймаут,
  фоновый приоритет потока, сон между проверками.
- **Полный режим** (все 16 целей) — переключается в Настройках → Проверка.

## Оформление (Настройки → Оформление)

- Темы: **Алый**, Фиолет, Изумруд, Океан, Закат — кнопками, **применяются
  мгновенно без перезапуска** (таблицы, тексты, скроллбары, выпадашки, шторка).
- Шрифт интерфейса: **Trebuchet MS** (по умолч., крупнее) / Calibri / Segoe UI /
  Verdana / Tahoma и др. — только установленные в системе; выбор сохраняется
  сразу, вступает в силу после перезапуска (программа спросит сама).
- Масштаб: Компактный / Обычный / **Крупный** (по умолч.) / Очень крупный.
- Моноширинный для логов: Cascadia Mono / Cascadia Code / Consolas / Lucida Console.
- Скроллбары, чекбоксы, списки, терминалы-тексты (включая цвет выделения
  и курсор) и выпадающие списки — в цветах текущей темы.

## Автопереключение

Мониторинг каждые N минут (по умолч. 3) проверяет текущее соединение без
перезапуска `winws`:

- `ping` до хостов из целей (порог по умолч. **5000 мс** / таймаут);
- HTTPS-проверки (`curl -I`, fallback `urllib`).

Если **>50% HTTP провалились + массовые проблемы пинга** (классический признак
DPI-блокировки) — приложение ставит лучший известный конфиг через `sc create zapret`,
сохраняет в журнал и показывает уведомление-тост.

## Запуск

1. Установите Python 3.10+ **с сайта python.org** (не из Microsoft Store!)
   с галочкой `tcl/tk`. Store-версия запрещает менять иконку таскбара —
   там всегда будет логотип Python, кодом это не обойти.
2. Двойной клик по `run.bat` (сам запросит права администратора).
   Без админа `winws.exe` / `WinDivert` не запустятся — в UI будет предупреждение.
3. При первом запуске укажите корневую папку zapret
   (где лежат `general.bat`, `service.bat`, папки `bin/`, `lists/`).

## Если иконка не сменилась

1. Снимите старое закрепление с таскбара (ПКМ → открепить).
2. Пересоздайте ярлык: `install.bat` или Настройки → Приложение → ярлык.
3. Настройки → Приложение → «🔄 Обновить кэш иконок Windows»
   (проводник мигнёт). Если не помогло — перезагрузка.

Прямой запуск без bat:

```
python app.py
python app.py --minimized   :: для автозагрузки
```

## Автозагрузка приложения

Настройки → Приложение → «Запускать вместе с Windows (**с правами администратора**)».
Реализовано задачей планировщика `ZapretManager`: триггер при входе в систему,
галочка «с наивысшими привилегиями». Создание задачи один раз спросит UAC.
Старый вариант через реестр `HKCU\...\Run` автоматически подчищается.

## Файлы

```
zapret-app/
  app.py            — всё приложение (ядро + UI)
  run.bat           — запуск с запросом UAC
  install.bat       — создание ярлыка с иконкой
  version.txt       — версия для автообновления
  requirements.txt  — пустой (stdlib only)
  assets/
    icon.ico/.png   — чёрный квадрат с белой Z
  data/             — создаётся само (не коммитить: настройки/логи/история)
```

## Энергоэффективность

- Нет анимаций/таймеров с частым тиком; UI обновляется через `after(250)` только очередью.
- Мониторинг спит через `Event.wait(interval)` — 0% CPU между проверками.
- Проверки последовательные, процессы `winws` всегда останавливаются после теста.
